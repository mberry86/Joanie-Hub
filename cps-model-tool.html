Formula reference
Base CPS = Seasonal CAC Target ÷ Historical Effectuation Rate
Adjusted CPS = Base CPS × Seasonality Index × Persistency Adj. Factor
Max CPS Ceiling = 90-Day LTV × Max CAC % (CFO-approved)
Tier CPS = Adjusted Base CPS × ( 1 + Tier Uplift % )
Persistency Adj. = 1.0 if source ≥ cohort avg · 0.95 if source lags cohort by > 5%
Persistency adjustment applies at next-season reset only. Partners notified 30 days pre-season (preliminary) and 7 days pre-season (final). No retroactive mid-season CPS changes.
