What to Pull from Looker
Joanie Dashboard · 4 exports
How to export

In Looker, go to the Joanie Dashboard. Use the shared "QM RP Weekly Export" look group. Export each of the four reports below as CSV with headers. Zip all four files together and upload to this project chat.

File Looker Report / Look Key Columns Used
source_performance.csv
 Source Performance · grouped by Source + Month Inbound Contacts, D1 QM Unique 60+s, QM Marketing Spend, Net Policies, Media CPA, Avg Policy LTV, GP, GP per Talk Hour, SCR 60+s%, Cost per D1
source_subids.csv
 Source + Sub ID Performance · by Source + Campaign Angle Campaign Ad Type, Campaign Product, Campaign Angle, all performance columns — identifies creative angle (grocery, flex-card, OTC, etc.)
mpqs_durability.csv
 MPQS Durability · grouped by Source + Week CR%, Talk Hours, Net Sales, Eff%, RDE%, % Sales Over 75, 1–3 Month Persistency %
source_age_bands.csv
 Age Band Breakdown · by Source % of Sales by age group — specifically i: 75+ column which feeds the Age75+ MPQS KPI
Intraweekly runs

For mid-week updates, export the same four files with the current month's data accumulated to date. The date picker on the dashboard will show the correct period automatically. No other changes needed.

02
How to Run the Update
3 steps
1
Upload the Joanie zip to this Claude project
Zip all four CSV files from Looker into a single file (e.g. SEP_to_date_Joanie.zip) and upload it directly to the chat in this shared Claude project. You do not need to rename the files — Joanie reads all four by name automatically.
This project · Shared workspace
2
Type your run message
A simple message is all that's needed. Joanie will read the SOT from project files, process all four data sources, run MPQS scoring, calculate Right Pricing bids, generate scorecards, and produce the updated dashboard HTML. You can say something as simple as:

"Run MPQS, Right Pricing and Scorecards for [month] with the attached files"

Joanie will confirm what data it found, show a publisher-level summary, and deliver the updated file.
Natural language · No special syntax
3
Download the output and verify before going live
Joanie delivers a single HTML file (e.g. qm_rp_[month]_final.html). Open it locally and spot-check three things before replacing the live SOT:

(a) Page loads with no spinner hang
(b) Pick one publisher you know well — confirm their partner card shows correct Raw Calls, D1, Net Sales, and CPA
(c) Switch the date picker from the current month to the prior month — confirm all numbers change

If all three pass, replace index.html in this project with the new file. That becomes the new SOT for all future runs.
SOT update · Replace index.html

04
The Locked Rules — What Changes vs What Never Changes
Read carefully
Critical — SOT integrity

Every run starts from index.html in this project (the SOT). Joanie never works from a previous output file. The SOT is the single source of truth for all JS functions, CSS, HTML structure, and OEP/AEP season data. Only the data blocks below are ever updated.

✓ Updated every run
  • NOTION_DATA — publisher scores for current month (22 pubs × 3 seasons)
  • SCORECARD_DATA — new month's rows prepended; all prior months kept for date picker
  • AGG_CPD1 / TGT_CPD1 — aggregate cost-per-D1 constant
  • Date picker defaults — 8 find/replace strings updated to current month
✗ Never touched
  • All JS functions — loadData, renderRP, buildPartnerCard, dpRender, etc.
  • CSS and HTML structure — layout, styling, colors, fonts
  • OEP and AEP data in SCORECARD_DATA — preserved verbatim from SOT
  • var DP declaration — must stay with state vars at top of script
  • SUBID_DATA, MPQS_MULT, SEASONS config — only changed by explicit request

06
Using the Date Picker
Functional as of May 2026
📅
Month mode (default)
The dashboard defaults to the current run month. Click the month input, select any prior month, and all tables, charts, partner scorecards, and the ticker update immediately to that period's actuals.
📆
Custom range, Week, Day, Year modes
Switch modes using the Day · Week · Month · Year · Custom buttons. For intraweekly analysis, use Custom to set a specific date range. The dashboard filters all publisher data to only rows with dates within that window.
↺
Reset button
The ↺ button in the date picker resets to the current run month. Use it to return to the latest data after browsing historical periods.
